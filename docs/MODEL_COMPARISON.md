# Model Performance Comparison Matrix — MoleculeScope

This document compiles the performance of all 18 primary experiments and control baselines evaluated on both the Stratified Random Split and the Bemis-Murcko Scaffold Split.

*Note on Model Roles:* The metrics listed in Section 1 and Section 2 represent the baseline **evaluation models** trained on the 6,236 train samples and evaluated on the 1,559 test samples. The final **production model** will be generated by retraining the selected architecture (**Random Forest on 11 descriptors**) on all 7,795 cleaned molecules during Phase 6.

## 2. Key Comparative Metrics Analysis

### A. Baseline Comparisons
*   **Stratified Random Split Majority Baseline:** Accuracy of **63.57%**, Macro F1 of **0.3886**. All machine learning models outperform this baseline comfortably, establishing robust learning signatures.
*   **Scaffold Split Majority Baseline:** Accuracy of **60.94%**, Macro F1 of **0.3786**. The drop in baseline accuracy reflects the natural distribution shift inside the scaffold test slice.

### B. Best Performers by Target Split
*   **Random Split Winner:** **Random Forest on Descriptors** achieved the best accuracy (**87.36%**) and Macro F1 (**0.8604**). However, for probabilistic ranking power, **Logistic Regression on Combined Features** achieved the highest ROC-AUC (**0.9466**).
*   **Scaffold Split Winner:** **Random Forest on Descriptors** achieved the best classification accuracy (**74.47%**) and Macro F1 (**0.7212**). For ranking capability on novel scaffolds, **XGBoost on Combined Features** achieved the highest ROC-AUC (**0.8138**) and PR-AUC (**0.8684**).

## 3. The Generalization Gap (Random vs. Scaffold)

Evaluating models on identical sample sizes but grouping by Bemis-Murcko scaffolds reveals the "generalization gap":

1.  **Representations Sensitivity:**
    *   *Descriptors Only:* Random Forest Macro F1 drop is **-0.1392** (0.8604 $\rightarrow$ 0.7212). The physicochemical properties generalize well.
    *   *Fingerprints Only:* Logistic Regression Macro F1 drop is **-0.2172** (0.8488 $\rightarrow$ 0.6316). Tree-based classifiers show a massive drop (Random Forest Macro F1 drops from 0.8172 to 0.5546). Fingerprints are sparse, ECFP-specific features that fail on unseen scaffolds.
    *   *Combined Features:* XGBoost Macro F1 drop is **-0.1730** (0.8568 $\rightarrow$ 0.6838).
2.  **Implications for Drug Screening:**
    *   For testing chemical libraries with high scaffold diversity, descriptors-only models or combined representations with strong tree regularizations (such as XGBoost) are required to prevent structural overfitting. Fingerprint-only models will lead to high false-positive rates on new structural classes.
